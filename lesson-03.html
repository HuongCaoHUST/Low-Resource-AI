Web tĩnh và GitHub Pages

Đóng gói tài liệu thành website tĩnh có thể xuất bản miễn phí.

Mục tiêu

  • Hiểu khác biệt giữa source code và thư mục website.
  • Kiểm tra liên kết trước khi deploy dưới project URL.
  • Tự cập nhật nội dung HTML.

Từ source đến website

Website này chỉ gồm HTML, CSS và một file JavaScript nhỏ cho menu mobile. GitHub Pages có thể phục vụ trực tiếp các file này mà không cần backend hoặc bước build.

git add .
git commit -m "docs: update lesson"
git push origin main

Bài tập

Thêm một trang HTML mới trong repository, cập nhật liên kết ở trang Bài học, rồi kiểm tra nó trên GitHub Pages.
